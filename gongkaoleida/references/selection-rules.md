# 公告筛选与评分规则

> 当前运行评分：`V2.0-rule-calibrated-provisional`，自2026-08-15起启用。该版本已按用户确认重分配规则权重，并用潘代明人工金标准校准同一公告的等级边界；尚未用志公抖音、小红书正负作品完成流量验证。评分不是岗位客观价值，也不是平台流量保证。

## 零、先区分事实、基础分和平台建议

每条公告先提取并标准化`单位类别`：事业单位综合、教师、医疗、辅警、国企、银行、基层工作者、劳务派遣、见习或其他。单位类别与`编制/用工性质`分开，不能把“政府办公室”写成有编，也不能把“辅警”当作用工性质。

待遇固定分三种证据：`官方原文`、`官方未公布`、`内部参考估算`。用户清单默认只展示官方原文；内部估算必须写依据和“非公告原文”，不能用估算反向核定公告事实。

基础分只在通过硬校验后生成；未通过者固定记为`not_scored`，评分显示`—（未评分）`，不得写0分。平台建议另记为`抖音优先`、`小红书优先`、`双平台`或`暂不制作`。平台适配规则按 [content-performance-calibration.md](content-performance-calibration.md) 用真实作品数据校准。

## 一、硬校验

以下条件全部通过后才评分：

1. 广西范围；
2. 真实招录公告；资审、成绩、面试、拟录用/拟聘用等名单线索先路由到独立名单素材队列，不参与本表评分；
3. 官方发布日期位于用户指定窗口；
4. 报名未截止，或报名尚未开始且时间明确；
5. 官方原文或可靠一手主体可核验；
6. 人数、最低学历、报名时间、用工性质已确认；
7. 没有以博士、博士后、副教授、副高、正高等高门槛岗位为主要目标；
8. 不是与志公目标受众明显无关的内容。

高门槛公告若存在可独立拆分的本科/大专岗位，按这些岗位实际人数重新判断，禁止用公告总人数放大。

硬校验与核验完成度不得混写。已经找到官方原文并确认“不在窗口、已截止、非社会招聘、受众硬不匹配、官方未发布必填事实或属于重复线索”，代表核验成功但不具备评分资格；只有一手证据链在全部自核路径后仍无法取得，才属于`evidence_failed`，并阻断整批完成。

## 二、核心入选逻辑

优先：

1. 广西地区招聘，目标受众实际可报人数不少于10人，且有事业编、控制数或行政编原文；
2. 好单位，即使人数不足10人也可进入；
3. 同类统一考试或可汇总系列，如统计机构协管员；
4. 国企、学校、医院、公安辅警等非传统公考岗位，只要单位、人数、学历、时效和受众价值成立；
5. 劳务派遣的高等级例外必须同时满足：去向单位好、地区好、最低学历以大专及以上为主。

人数多但单位普通、地区弱、学历过低的劳务派遣，只能作为C级补充，不因数据大直接升至A/B。

### V2.0固定取值档位

同一事实必须落入同一档位。不能为了得到预期等级临时改分；确需人工校准时只走“人工金标准”规则。

| 维度 | 固定档位 |
| --- | --- |
| 志公受众与招聘类别匹配（15） | 15：正式公考/事业单位/教师等核心考编类别；12：国企、医院、学校编外、辅警等强相关类别；9：政府去向或公共服务类；6：普通派遣、见习或临时岗位；3：边缘相关。明显无关直接硬排除 |
| 目标受众实际可报规模（25） | 100人及以上25；50—99人22；20—49人18；10—19人14；5—9人9；1—4人5。只计目标受众实际可报人数 |
| 单位与地区吸引力（15） | 15：自治区/核心地市机关、重点公共单位、强校强院或大型国企；12：地市级或认可度较高的公共单位、市属国企；9：县级或一般公共单位；6：普通单位；3：吸引力弱 |
| 编制、合同与待遇稳定性（15） | 行政/事业编15；控制数14；国企正式劳动关系12；医院/公共单位直签编外8；辅警直签劳动合同7；劳务派遣5；顶岗/临时4；见习2 |
| 学历及报考门槛覆盖（10） | 大专及以下广覆盖10；大专/本科混合且限制较少8；本科为主6；硕士或较高职称门槛占主导但可拆分3。博士、副高等高门槛为主且不可拆分时硬排除 |
| 统一考试与内容传播价值（15） | 多地同类统考/系列15；大规模数据或强反差13；类目清晰且有明确内容钩子10；单一地区有基础钩子7；传播点弱4 |

基础分等于七个维度之和。人工等级金标准命中同一公告时，保留`base_score`，并将最终分校准到人工等级最近边界；相似公告不得继承人工等级。

## 四、人工金标准与机器参考等级

将潘代明直接标注的`operator_gold`作为选题优先级金标准，使用SS/S/A/B/C五级：

- SS：极少数必做选题，通常同时具备超大规模、核心考编受众和强类目价值；
- S：高优先级必做，包括核心受众强公告、统一考试或可形成多地系列的题材；
- A：明确值得做，但存在非编、实际可报受众缩水、门槛较高等上限因素；
- B：可用补充，有单位、类目或地区亮点，但规模小、顶岗/派遣/辅警等性质限制明显；
- C：低优先级库存，仅有局部亮点，一般不作为当日主选。

人工金标准与机器分冲突时同时保留两者，相同或高度近似公告优先参考人工标注，不得用机器分静默覆盖。人工金标准只证明“值得发的运营判断”，不等于已经验证平台流量。

当前 V2.0 的参考等级按下列分数带计算：

- SS级：95—100分；
- S级：85—94分；
- A级：75—84分；
- B级：65—74分；
- C级：55—64分；
- 55分以下：内部观察，不进入用户榜。

B级只放宽人数、单位吸引力等软条件；不放宽时效、官方来源和必填字段。

C级可继续放宽人数、地区、学历、用工性质和传播价值，但必须至少有一个明确亮点；仍不得放宽官方来源、日期、报名状态、必填字段和高门槛排除。

## 五、特殊判断

### 劳务派遣

- 好地区＋好单位＋大专以上：只代表具备继续评分资格，不再自动保证B级；
- 去向单位好只是软加分，仍需同时看人数、目标受众、官方待遇、合同关系和历史内容表现；
- 少人数、本科门槛、低待遇且为劳务派遣，又没有独特话题的公告，通常为C级或内部观察；
- 只满足好地区、好单位、大专以上中的一两项：最高C级；
- 单位普通、地区弱、目标受众弱：内部观察或排除。

### 教师、学校和医院

- 公办名校、优质医院、明确人数和报名窗口可以作为好单位例外；
- 代课、顶岗、见习、临聘必须写明非编或用工性质；
- 高学历医师岗位不因医院知名而放宽硬排除。

### 公安辅警

- 直接与公安机关签订劳动合同和劳务派遣分开评分；
- 不得写成公务员或行政编；
- 学历放宽只适用于定向人群时必须显式标注。

### 平台路由

- 抖音与小红书不得共用“可发/不可发”的单一结论；
- 小红书可以承接更本地、更细分和更快时效的公告图文；抖音优先考虑受众广度、规模、反差和历史同类内容表现；
- “辅警、教师、医院优先于普通劳务派遣”当前只作为运营经验先验，不作为跨平台永久硬规则；
- 运营人员对样本做盲评时不得先看机器权重和当前分数，避免用模型解释模型。

### 历史仍可报名

官方日期早于窗口但仍在报名的公告，只进入历史池，不参与本轮S/A/B/C主排序。聚合平台当日重收录不能改变时间池。

## 六、稳定性

同一公告在事实、规则和截止时间未变化时，固定评分不得改变。需要调整时写明是事实修正、规则变化还是报名状态变化。

评分因平台实绩校准发生变化时，必须同时写明旧版本、新版本、样本范围和变化原因。没有正负样本、账号口径和平台拆分时，不得声称“已经找到了最准的评分”。

## 七、名单与招录进度公告路由

下列公告不执行S/A/B/C招聘评分，进入独立名单/进度队列：

- 面试资格审查、资格复审名单；
- 笔试、面试、综合成绩和入围名单；
- 面试公告、面试名单；
- 体检、考察名单；
- 拟录用、拟聘用公示；
- 递补、补录、取消资格和更正公告。

名单/进度线索先留内部总账。只有符合 [list-content-rules.md](list-content-rules.md) 的硬准入、完成附件解析并得到可复算结论后，才进入`名单型视频素材表`并执行独立素材评分。不能把名单人数计入新增招聘人数，也不能因无法报名而标记为“已截止招聘”。

同一招录项目的不同阶段使用独立进度稳定ID并关联父公告ID。更正公告关联被更正的进度记录，不静默覆盖原值。
