# 广西固定官方招聘来源矩阵

## 一、定位

本矩阵用于补足公考雷达聚合遗漏。公考雷达、官方站和人才网分别独立发现线索，再按官方URL或公告指纹去重。任何单一来源都不能被假定为覆盖广西全部招聘信息。

入口以2026-08-14核验结果为基线。站点改版或入口失效时，从上级政府官网、自治区人社厅友情链接或广西人才网主站重新定位，并在来源日志记录变更；不要猜URL。

## 四、每个地市的扫描动作

1. 扫人社局或政府站的通知公告、人事信息、事业单位招聘、就业创业和公示栏目；
2. 使用站内搜索补查两组关键词：招录组“招聘、聘用、编外、劳务派遣、辅警、教师、医院、国企、见习”；名单素材组“资格审查、资格复审、笔试成绩、面试成绩、综合成绩、总成绩、入围名单、面试名单、体检、考察、拟录用、拟聘用、公示、递补、补录”；
3. 扫人才网公告资讯和单位招聘，不只看普通企业职位列表；
4. 命中县区或主管部门线索后，继续进入县区政府、教育局、卫健委、公安局、国资委或单位官网；
5. 记录栏目页数、近三天线索数、官方日期、失败入口和替代入口；
6. 与公考雷达结果按官方URL、单位、标题主体和官方日期去重；招录公告与后续进度公告建立父子关联，但不合并成同一条记录。

## 五、覆盖判定

- 只翻完公考雷达：`公考雷达近三天完整扫描`；
- 公考雷达、自治区3个固定来源、14市人社/政府入口和人才网地市层均完成：`核心来源完整扫描`；
- 还覆盖县区、垂直单位、官方公众号和工作群：才可写`本轮完整扫描`；
- 任一固定来源未完成：`当前已核验下限`，并列出缺口。
